🚀 Getting Started
1. Clone the repository
git clone https://github.com/DuvvariMohankrishna/python-learning.git
2. Navigate to the project directory
cd python-learning
3. Create a virtual environment (optional)
python -m venv venv
4. Activate the virtual environment

Windows

venv\Scripts\activate

macOS/Linux

source venv/bin/activate
5. Install Jupyter Notebook
pip install jupyter
6. Start Jupyter Notebook
jupyter notebook

Open any .ipynb file and run the cells to explore the examples and practice exercises.
